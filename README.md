# StopPlayingUCDR 

The ultimate tool for breaking the cycle and taking back your time
StopPlayingUCDR is a lightweight Chrome extension designed with one thing in mind:
Instantly closing any tab opening Untitled Combat Demo Rework on Roblox before you can fall back into the loop!

#  Key Features 

Checks Game ID 
Gives motivational message telling you to stop trying to play!
Fully Local!

# Why?

Let's admit it, some people have habits of coming back to things they swore they'd stop playing. 

This should help.
