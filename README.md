# StopPlayingUCDR 

The ultimate tool for breaking the cycle and taking back your time
StopPlayingUCDR is a lightweight Chrome extension designed with one thing in mind:
Instantly closing any tab opening [Untitled Combat Demo Rework](https://www.roblox.com/games/10168763039/Untitled-Combat-Demo-Rework) on [Roblox](https://www.roblox.com) before you can fall back into the loop!

#  Key Features 

Checks Game ID 
Gives motivational message telling you to stop trying to play!
Fully Local!

# Why?

Let's admit it, some people have habits of coming back to things they swore they'd stop playing. 

This should help.

# What it can't do
Stop you from launching the game via the Roblox App
Stop you from joining through friends
Stop you from starting the Roblox App with parameters to join the game.
Why?
Because this is an extension.
