# StopPlayingUCDR 

The ultimate tool for breaking the cycle and taking back your time
StopPlayingUCDR is a lightweight Chrome extension designed with one thing in mind:
Instantly closing any tab opening [Untitled Combat Demo Rework](https://www.roblox.com/games/10168763039/Untitled-Combat-Demo-Rework) on [Roblox](https://www.roblox.com) before you can fall back into the loop!
